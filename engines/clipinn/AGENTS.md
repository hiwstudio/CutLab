# Clipinn agent notes

- Read README.md before operating Clipinn.
- Use operator mode. The engine launcher enables it, so the agent fulfills
  selection and visual-review task files without a second model call.
- Use blur style by default. Ask the user before changing font, caption zones,
  subtitle zones, or clip count.
- Keep the selection quality bar. Reject weak candidates rather than filling
  a requested count.
- Preserve Timing Maps and downloaded segments so a paused run can resume.
- Import rendered clips into CutLab for further timeline edits.
